# camunda_cluster_backups (Data Source)

List the backups of a cluster, for example to pick one to restore.

## Example Usage

```terraform
data "camunda_cluster_backups" "all" {
  cluster_id = "00000000-0000-0000-0000-000000000000"
}

output "completed_backup_ids" {
  value = [
    for backup in data.camunda_cluster_backups.all.backups : backup.id
    if backup.status == "Complete"
  ]
}
```
