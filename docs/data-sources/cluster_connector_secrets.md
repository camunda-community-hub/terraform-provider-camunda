# camunda_cluster_connector_secrets (Data Source)

List the names of the connector secrets of a cluster. The values are deliberately not exposed, so they don't end up in state.

## Example Usage

```terraform
data "camunda_cluster_connector_secrets" "all" {
  cluster_id = "00000000-0000-0000-0000-000000000000"
}

output "secret_names" {
  value = data.camunda_cluster_connector_secrets.all.names
}
```
