# camunda_audit_log (Data Source)

The activity log of the organization. The Console API returns all events at once and offers no filters; filter them in Terraform. Requires a client with permission to read the activity log.

## Example Usage

```terraform
data "camunda_audit_log" "all" {}

output "cluster_creations" {
  value = [
    for event in data.camunda_audit_log.all.events : event
    if event.entity == "cluster" && event.audit_type == "create"
  ]
}
```
