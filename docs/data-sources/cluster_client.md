# camunda_cluster_client (Data Source)

Read a client of a cluster, with the details needed to connect to it. The client secret is only returned when the client is created, so it is not available here.

## Example Usage

```terraform
data "camunda_cluster_client" "worker" {
  cluster_id      = "00000000-0000-0000-0000-000000000000"
  zeebe_client_id = "zeebe-client-id"
}

output "zeebe_address" {
  value = data.camunda_cluster_client.worker.zeebe_address
}
```
