# camunda_cluster_clients (Data Source)

Read all clients of a cluster, with the details needed to connect to the cluster. Client secrets are only returned when a client is created, so they are not available here.

## Example Usage

```terraform
data "camunda_cluster_clients" "all" {
  cluster_id = "00000000-0000-0000-0000-000000000000"
}

output "client_names" {
  value = [for client in data.camunda_cluster_clients.all.clients : client.name]
}
```
